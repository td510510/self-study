## Cấu trúc chuẩn

Mỗi tuần trong giáo án gồm 4 khối: **① Lý thuyết → ② Code ví dụ → ③ Thực hành (có lời giải) → ④ Đồ án tuần**.
Hệ thống đồ án 4 tầng: bài thực hành → đồ án tuần → 10 đồ án môn học (kèm `BAOCAO.md`) → 4 sản phẩm portfolio + đồ án tốt nghiệp.

## Bắt đầu từ đâu

1. Đọc lộ trình → làm **Tuần 0 (setup, 5h)**.
2. Mở giáo án Tuần 1, làm theo 5 buổi/tuần.
3. Mỗi tuần đóng 1 commit vào repo `ai-engineer-journey`, cập nhật `PROGRESS.md` và `ERRORS.md`.

## Trạng thái

Lộ trình đã hoàn chỉnh: **40 tuần · ~367 giờ · 40 đồ án tuần · 10 đồ án môn học · 4 sản phẩm portfolio · đồ án tốt nghiệp · ~150 bài thực hành có lời giải.**

Bộ tài liệu đã đủ dùng từ tuần 0 đến lúc đi phỏng vấn.
